# ConstructIQ — Engineering & Construction Intelligence Platform

A high-performance construction management, site telemetry, and structured **Project Intelligence** platform designed for high-rise real estate, civil engineering, and infrastructure contractors.

Designed with an authentic **architectural and engineering editorial aesthetic**:
- **Strict Light Mode** palette: Warm Graphite (`#252525`), Warm Off-White (`#F7F6F2`), Pure White (`#FFFFFF`), Concrete Gray (`#E5E3DD`), restrained Terracotta Orange (`#C96B3B`), and Muted Olive (`#6F7658`).
- **No generic AI SaaS cliches**: Zero neon gradients, no chatbot bubbles, no glowing cards.
- **Enterprise Engineering Command Center**: High-contrast, tabular data, IS 456 compliance, structural telemetry, and Primavera baseline tracking.

---

## Key Modules & Capabilities

### 1. Command Center Dashboard
- **Active Site Header**: Real-time project telemetry for `SUNRISE RESIDENCY` (*Ahmedabad · 3 Towers · 18 Floors*), Project Health composite score (`82%`), and construction status beacon.
- **Prioritized Attention Items**:
  - `01 STEEL DELIVERY DELAY` (Tower A · Procurement · High Priority)
  - `02 CEMENT INVENTORY` (Basement B2 · Materials · Medium)
  - `03 ELECTRICAL WORK` (Tower B · Schedule · Monitoring)
- **Superstructure Elevation Matrix**: Interactive tracking of Tower A, B, and C floor cycles (MIVAN shuttering, curing, and concrete pours).
- **Engineering Quality Log Strip**: Certified field supervisor inspection results and cube test verifications.

### 2. Structured "Project Intelligence" Engine (Ask Project)
Replaces traditional conversational chat interfaces with **Structured Engineering Intelligence Reports**:
- **Kicker & Question**: Targeted inquiry across schedule, procurement, quality, and cost domains.
- **Root Cause Analysis**: Pinpoints exact field bottlenecks and supplier logistics.
- **Impacted Activities**: Direct impact on downstream activities (e.g. column casting, tie-beam reinforcement).
- **Schedule & Cost Impact**: Quantified schedule slippage (`+4 days`) and financial exposure (`₹1.8L`).
- **Recommended Actions**: Clear step-by-step mitigation workflows.
- **Auditable Sources**: Traceable citations to daily logs, purchase orders, and Primavera P6 baseline schedules.
- **Printable Dossier**: One-click generation of formal engineering memos.

### 3. Master Project Data & Specifications
- Comprehensive structural parameters (RCC shear walls, M35/M30 concrete, Fe550D rebar, IS 1893 seismic compliance).
- Phase 2 Bill of Quantities (BOQ) with commitment ledger, balance, and variance analysis.
- Contractor roster with workforce counts and safety compliance audits.

### 4. Daily Site Updates & Telemetry
- Timestamped daily logs (`Site Update #24`, `#23`, `#22...`).
- Automated weather telemetry (Ahmedabad 34°C dry condition).
- Detailed workforce trade allocation (bar benders, masons, carpenters, MEP technicians).
- Heavy plant & machinery uptime metrics (Tower cranes, batching plant, concrete boom placer).
- Field photographic engineering verifications.
- Interactive modal to record new certified site entries.

### 5. Work Breakdown Structure (Tasks)
- Filterable task board categorized by trade (Civil, Procurement, Materials, MEP, Fire Safety).
- Blocker tracking and assignment deadlines.

### 6. Risk Mitigation Registry
- Geotechnical, supply chain, and quality compliance risk matrix.
- Contingency reserve tracking and HSE safe hours (Zero LTI).

### 7. Certified Engineering Reports & Dossiers
- Weekly Superstructure Execution Progress Reports.
- Quality Assurance Cube Test Dossiers.
- Financial BOQ Escalation Audits with digital engineer sign-offs.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Development
```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### Production Build
```bash
npm run build
```
